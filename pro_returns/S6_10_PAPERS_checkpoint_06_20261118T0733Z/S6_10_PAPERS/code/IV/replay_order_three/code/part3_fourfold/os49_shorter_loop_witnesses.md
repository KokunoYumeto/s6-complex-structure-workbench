## 7. Exact scalar-loop witnesses and the range

For \(k=1\), the new parameter is the original scalar itself:
\(\lambda=w\). Take the literal oriented fan basis
\[
 v=(1,0),\qquad w_{\rm fan}=(-4,1),\qquad
 \det(v,w_{\rm fan})=1,\qquad \delta=(0,1)=4v+w_{\rm fan}.
\]
Thus \(S=13\), and the actual positive scalar loop has
\[
 [\Sigma_{\Phi,T}]=\frac{(13-1)(13-3)}4=30=2\pmod {28}.
\]
This example uses the shorter family itself and does not select a cube root
of a homotopy-sphere class.

The exact \(k=1\) range is
\[
                  \{0,2,6,12,14,16,20,26\}.                    \tag{OS.15}
\]
For an upper bound, the formula depends on odd \(S\) modulo 112. Evaluating
those 56 residues gives exactly the set displayed. Every value is attained
by the following primitive physical cocharacter pairs:
\[
\begin{array}{c|r|r}
 (a,b)&S=a^2-ab+b^2&[\Sigma]\pmod {28}\\ \hline
 (0,1)&1&0\\
 (1,4)&13&2\\
 (1,3)&7&6\\
 (3,14)&163&12\\
 (1,6)&31&14\\
 (2,5)&19&16\\
 (1,10)&91&20\\
 (3,7)&37&26
\end{array}
\]
These are actual fan coordinates. For any displayed coprime pair choose
integers \(r_0,s_0\) with \(ar_0+bs_0=1\), and set
\(v=(b,r_0)\), \(w_{\rm fan}=(-a,s_0)\). Then
\(\det(v,w_{\rm fan})=1\) and \(av+bw_{\rm fan}=(0,1)=\delta\).
Thus each row supplies the required actual unimodular fan, with no
realizability inference from an unattained residue.

All values for every \(k\) are even: with \(S=2j+1\), (OS.3) is
\(kj(j-1)\). Conversely the fixed \(S=13\) fan gives \(2k\) modulo28.
As the actual cap order \(m=3k\) varies through the already constructed
positive integers, these shorter scalar families therefore realize exactly
the fourteen even classes. The proof of source-translation endpoint
minimality is retained separately with its explicit scope; it is not used
to infer these realized classes.
