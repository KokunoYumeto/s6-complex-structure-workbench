# B.4.26: a necessary geometric property of any cap

Owner: classification_e. 15 November 2026. **Proved; root and boundary_d complete-source referees passed.**

Unlike B.4.24, this statement does not assume that the unknown cap is a logarithmic torsor. It assumes a proper holomorphic map of a smooth fourfold to the fixed bidisc, flat over the original parameter r and agreeing with the actual partial family off the origin. Every irreducible origin-fibre component must then be a threefold.

The bridge is a finite multisection. A point of local fibre dimension2 admits a generic two-plane slice giving a finite surjective representative over an entire smaller bidisc. Normalize that surface; it is Cohen–Macaulay and hence finite flat over the smooth bidisc. The positive-degree trace of its points is holomorphic on the ordinary torus locus. Along each punctured axis all other branch curves have been excluded by shrinking, so the finite cover is locally a disjoint union of cyclic root covers. In an actual fan chart a pulled-back character is t^k times a unit. Its multiplicative norm is x^k times a unit for x=t^e, with an integral bounded ghost. Thus the traces extend as log-torus sections in both of the verified axial origins and differ by dF. The nonzero dγ ghost-monodromy class of B.4.24 excludes this for every positive d.

The argument does not make an arbitrary cap a torsor. It instead uses a map from one finite surface into the known fan charts on the punctured base, where the log trace is explicitly constructed. It excludes equidimensional caps and even a single two-dimensional component of the origin fibre. Flatness over r bounds all components by dimension3, so the remaining possibility is precisely vertical threefolds. This is compatible with the scope allowed by the prompt and does not settle unrestricted B.4.

The holomorphic fixed-bidisc map is an explicit hypothesis. If a proposed r-proper filling initially extends q only meromorphically, its graph modification must be retained; no claim is made that its fibre geometry stays unchanged. The actual origin cap and its B.5 invariants remain Open.
