# Superseded inner-boundary comparison

The initial paragraph correctly constructed a weighted radial link, but its final identification with the stereographic-height link of F55 had not supplied an ambient comparison. It is superseded by the literal product-ball boundary B6 x interval, which meets the graph exactly in the F55 link. No return was promoted using the older paragraph.

Original paragraph, retained verbatim:

For precision, this link can be put in the ordinary six-sphere without
assuming radial injectivity. The map \((f,H)\) is homogeneous for the
positive weighted target action of weights \((2,3,1,1)\) on
\((X,y,\rho,\gamma)\). The squared Euclidean norm is strictly
increasing along every nonzero such orbit. Weighted radial projection
therefore gives a smooth embedding of the domain three-sphere in the
ordinary \(S^6\). Injectivity follows from the double-pair calculation;
transversality follows because the weighted radial vector is the image
of the domain radial vector. This is the exact lifted link used in F55.
