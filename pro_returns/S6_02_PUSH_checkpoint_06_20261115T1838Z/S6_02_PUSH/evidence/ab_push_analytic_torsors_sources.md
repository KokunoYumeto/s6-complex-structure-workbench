Opened primary source: Nicholas Buchdahl, *On compact Kähler surfaces*, Annales de l'Institut Fourier49(1)(1999),287–302, doi10.5802/aif.1674, https://www.numdam.org/article/AIF_1999__49_1_287_0.pdf. Theorem11 on printedp.297 states that every compact complex surface with even first Betti number is Kähler. The introductory summary onp.288 confirms the theorem's scope; no classification or algebraicity hypothesis is inserted.

The final TeX uses the already assembled key `Buchdahl1999` from the D references. The earlier standalone metadata file is retained as a comment-only pointer, so it cannot create a duplicate bibliography entry.

Opened primary source: Kuan-Wen Chen, *On the Hodge Structures of Global Smoothings of Normal Crossing Varieties*, arXiv2404.19229v2,16October2026, https://arxiv.org/pdf/2404.19229v2. Section2.1,p.8 explicitly states the domination result for the ddbar lemma and its consequence for Fujiki classC, referencing DGMS75 Theorem5.22. The parent's existing bibliography key `Chen2026HodgeRoot` is used; no duplicate entry is created here.

The result does not depend on a new numerical experiment. Its only numerical input, g(C)=q(E_C)=3, was proved in B.3.4. Equality of the rational R1 sheaves follows from the translation action on smooth elliptic fibres and on the oriented I12 polygon. The topological Leray edge sequence then proves b1(V)=6 for all analytic locally trivial torsors, including nontorsion classes. The proposition explicitly retains local triviality at the singular fibre and does not promote this to a classification of all possible analytic normalizations.
