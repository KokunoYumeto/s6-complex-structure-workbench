Root reported that the earlier target routine for01FZ used direct symbolic B*P^t multiplication. The new post-release program S6_SERIES_PUBLISH_II_A_01FZ_integer_certificate.py uses no symbolic library and no old code: it evaluates Gaussian-integer matrix entries at three integer points, combines these values with proved degree bounds to certify PJP^t=0, B=SPJ and BP^t=0, and uses fraction-free Bareiss determinants on a5×5 integer grid with degree bounds to certify the real determinant. A separately bounded3×3 grid certifies the squared-norm identity M^tM=(1+x²+y²)I. The infinity determinant is computed directly. Polynomial uniqueness on those grids proves the identities, not merely sampled numerical agreement. Output is exact and all assertions pass. This is a post-release different-method supplement to the existing scoped computation proposal; no additional prereading event is claimed.

Its output factors as (x1+x2+x3)(x1x2+x1x3+x2x3)/24. Root identified the earlier target input as a pre-expanded Todd polynomial.
