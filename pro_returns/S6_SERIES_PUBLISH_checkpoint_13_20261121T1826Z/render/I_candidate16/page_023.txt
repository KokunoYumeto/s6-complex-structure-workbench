Proposition 2.12 (The compactness radius). [tag 01Q8]
The exact set of nonzero parameters for which every ordinary fibre and both normalized finite
root fibres of Engel’s period-reference quotient are compact complex two-tori is
0 < |u| < e−2πM.
This is the parameter domain for the compact family with both smooth finite root models. The
condition on ordinary fibres alone at equality is determined by whether a maximizing point of
Dpart is ordinary; the maximizing locus is determined in proposition 25.6. For an independent
reference, the radius is |λ0|e−2πM.
Proof. 1. The function N(ξ, W) = |W| exp(2π Im µ Im ξ/ Im τ) is invariant under both line-
bundle period identifications. The inverse lift multiplies it by e2πDc. More directly the real
determinant of the four period columns is a nonzero sign times (Im τ)Dc. Thus the four
columns generate a full lattice exactly when Dc ̸= 0, and then the quotient is a compact torus
by a closed fundamental parallelepiped. At Dc = 0 their real span has dimension three; a
rank-four lattice in R4 cannot result, so the quotient cannot be a compact complex two-torus.
The function Dpart descends continuously to the connected base with the cusp removed and
tends to −∞at the cusp. Its image is therefore (−∞, M]: the maximum is attained, and the
intermediate value theorem fills all smaller values. Consequently Dc is nonzero at every base
point exactly when Im c < −M. Since |u| = e2π Im c, the assertion follows, with the indicated
reference scaling.
