## Current proof and the exact maps used

The replacement is printed as six numbered steps in
`papers/V/revisions/P1A3_tangent_duality.tex` and inserted identically in
the two active V body files. It changes no statement or numerical value.

1. Tensor the already rederived logarithmic cotangent sequence by
   K_M=h*L^-6. Its injection sends dq/q to the sum of the branch
   logarithmic forms; its quotient is h*F. This gives the end terms
   h*L^5 and h*(F tensor L^-6).
2. Projection formula and the two-column Leray sequence give endpoint
   cohomology (1,2,1,0,0) and (0,0,0,1,1). Every connecting-map target
   vanishes. The program enumerates every line weight independently.
3. The normalization residue map has a single global residue line. The
   unique logarithmic section has coefficient lambda^-5 in the actual
   kappa frame; its residue is a^-5, which is nonzero. Analytic Serre
   duality uses the displayed perfect evaluation pairing, so the
   ordinary twisted cotangent dimensions (0,2,1,1,1) reverse to the
   asserted tangent dimensions (1,1,1,2,0).
4. Direct projection of the supplied six-dimensional connection gives
   det(Q_lambda)=3/(625 lambda^6 (lambda-a)^3). Differentiating the actual
   parameter plane gives a rank-one nonzero P. Both maps use the same
   contraction of the translation-valued lattice cocycle.
5. The kernel of H1(T_A) -> H1(T_M|A) is exactly C Q at lambda=1, by
   the normal sequence and H0(O_A)=C. The actual determinant comparison
   shows P has nonzero image. Restriction of the global family cocycle
   is that image, proving the global class nonzero.
6. The classifying homomorphism C{u} -> C{s} has invertible linear
   coefficient and is injective. The miniversal defining ideal lies in
   its kernel and is zero. This gives the smooth one-dimensional germ
   and the local isomorphism from the actual family.
