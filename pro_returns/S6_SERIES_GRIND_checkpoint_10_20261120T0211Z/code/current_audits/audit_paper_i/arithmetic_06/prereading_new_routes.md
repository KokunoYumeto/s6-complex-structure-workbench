## A. Exterior-square linearization attempt

For a logarithm/period comparison matrix of M=[Z -> G_Q], put Betti weights in order (-2,-1,-1,0). The ordinary semiabelian rows can be arranged as

    P = [[t, k1, k2, v],
         [0, w1, w2, u],
         [0, e1, e2, z],
         [0,  0,  0, 1]],

where t=2*pi*i, z denotes the second-kind generalized logarithm, and the third row may differ from the displayed z by algebraic terms according to the chosen algebraic de Rham splitting. This does not alter the minor of the first two rows. The determinant defining compactness is the negative of the wedge-square entry with row (0,1) and column (1,3): k1*u-v*w1.

The six exterior Betti basis vectors have weights -3,-3,-2,-2,-1,-1, in lexicographic order 01,02,03,12,13,23. Therefore the actual input e1 wedge e3 has nonzero image in Gr_{-1}; it does not lie in W_{-2}. Twisting by the inverse Tate object raises weights by two. The W_{-2} subobject then has weights -1,0 and the Hodge types allowed for a 1-motive. The full exterior square additionally has weight +1. Thus the direct operation 'take this minor and apply the linear 1-period theorem to the W_{-2} truncation' has a concrete domain failure: its Betti input is outside that truncation. This is a statement about this exact construction, not an exclusion of all possible motivic relations or other methods.

A central change of comparison v -> v+t*s changes this minor by -t*s*w1. Neither t nor w1 vanishes. It therefore retains the central dependence instead of eliminating it by the exterior operation. I will check the precise source definition of the period theorem before using this observation as a source-comparison conclusion.

## B. Exhaustion of torus characters from a finite list of CM extension classes

Let alpha_1,...,alpha_r be elements of the CM order, and form the extension H_alpha of E by G_m^r with extension vector (alpha_1 Q,...,alpha_r Q). Use the principal polarization to identify extension classes with points; any pullback by an endomorphism must still use its Rosati adjoint.

For an integer character m=(m_1,...,m_r), its pushout has class (sum m_j alpha_j)Q. Since Q is nontorsion and every nonzero element of the CM field acts as an isogeny after clearing denominators, this class vanishes exactly when sum m_j alpha_j=0. The character lattice of H_alpha is therefore precisely the integer kernel of the two-row rational coefficient matrix of the alpha_j in (1,beta). The kernel is saturated, because the additive subgroup of K generated by the alpha_j is torsion free.

Choose a Z-basis of that image and complete a kernel basis to a basis of Z^r. This is an actual unimodular torus change. It gives an isomorphism of extensions

    H_alpha ~= H_(lambda_1,...,lambda_s) x G_m^(r-s),  s <= 2.

The split factors correspond to the displayed zero extension classes. For s=2, if lambda_j=a_j+b_j beta and n clears all denominators, the torus map with exponent matrix n*A and the base map [n] define an isogeny from G_Q x_E G_(beta Q) to the nonsplit factor: the required extension equality is (n*A)(Q,beta Q)^t=[n]^*(lambda_1 Q,lambda_2 Q)^t. Here [n]^* acts by n, so the equality is literal. The uniqueness of the extension homomorphism with these specified maps follows from Hom(E,G_m^2)=0.

Every character on H_alpha composed with an algebraic map from the nonsplit two-class extension is zero, because that source has no character. Adding split torus factors therefore adds only their chosen independent toric coordinates to this exact method; it supplies no character that evaluates the Gaussian coordinate on the original nonsplit source.

This exhausts the character approach for arbitrary finite lists of CM multiples of this fixed Q. It does not exhaust extensions with unrelated algebraic extension points, arbitrary analytic maps, or other transcendence methods. The proof uses the same known extension-class functoriality as C7.9--10; the additional result is the exact matrix reduction for every finite CM list.
