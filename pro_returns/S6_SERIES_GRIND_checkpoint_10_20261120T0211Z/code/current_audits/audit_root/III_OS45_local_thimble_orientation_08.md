# Explicit orientation of the local solid-torus map

In III_OS45_local_thimble_maps_08.md, the positive boundary angle of the
standard complex w-disc increases arg X and decreases arg Y. The marked
short action e1 is (X,Y)->(a^-1 X,aY), so this boundary loop is -e1.
The positive theta-loop is delta. Thus the standard product orientation
on the disc times the theta-circle gives boundary -e1 wedge delta.
Reversing the disc orientation gives the exact boundary +alpha used by
the positive prism and core-column conventions. The embedded image and
all coordinate maps are unchanged. Both orientations are recorded
explicitly before any global intersection or refined-class evaluation.

This addendum supplies no global framing value and no new whole-row
completion. The original local-map file and its receipt remain unchanged.
