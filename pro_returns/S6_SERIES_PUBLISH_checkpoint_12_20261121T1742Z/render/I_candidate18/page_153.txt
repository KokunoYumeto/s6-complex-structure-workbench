Proposition 20.5 (The unsubdivided cusp fan). [tag 02ZH]
For k, l ∈Z, let Pk,l be the cone defined by hq, hu ≥0, khq ≤y1 ≤(k + 1)hq and l(hq + hu) ≤
y2 ≤(l + 1)(hq + hu). These cones and their faces form a fan. Its two period automorphisms on
the cocharacter lattice are
G1(y1, y2, hq, hu) = (y1 + hq, y2, hq, hu),
G2(y1, y2, hq, hu) = (y1, y2 + hq + hu, hq, hu).
The affine chart of P0,0 is
U0,0 = Spec C[x, y, z, v, u]/(xy −uzv),
q = zv.
In particular the unsubdivided chart is not a smooth simultaneous model of the cusp.
Proof. 1. At fixed hq, hu ≥0, the cone Pk,l cuts out the rectangle
khq ≤y1 ≤(k + 1)hq,
l(hq + hu) ≤y2 ≤(l + 1)(hq + hu).
When hq = 0 the first interval is a point. These rectangles tile their support, and their
intersections are common faces, including this collapsed boundary.
This proves the fan
assertion. The displayed integral transformations preserve the fan and have integral inverses.
2. For a character (a, b, c, d), the six inequalities of the dual cone are c, a+c, b+c, a+b+c, d, b+d ≥
0. The characters
x = (0, 1, 0, 0),
y = (0, −1, 1, 1),
z = (1, 0, 0, 0),
v = (−1, 0, 1, 0),
u = (0, 0, 0, 1)
generate its integral monoid. Indeed if b ≥0 we subtract bx; if b < 0 we subtract (−b)y. The
remaining character has second coordinate zero and is a nonnegative integral combination of
z, v, u. The sole relation is x + y = u + z + v, and the character of the first base coordinate is
z + v. This proves the coordinate-ring assertion, including normality.
