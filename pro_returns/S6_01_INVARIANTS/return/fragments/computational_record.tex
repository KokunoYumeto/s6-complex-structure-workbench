\section{Computations, source verification, and scope of the remaining gaps}

All new arguments and code in this dossier are AI-produced by GPT-6 Astra
(OpenAI, ChatGPT Pro mode). We claim no priority. The supplied original
manuscript, its transcription, the workbench, course and reader notes
were treated as claims to check. The source manifest contains forty
file hashes, all of which were verified before extraction. Where a
transcribed formula mattered, we also inspected the original PDF;
the source-image checks include pages 5, 62--63 and 81. The local
correction in A4.1 concerns the original text itself, not merely OCR.

The exact computations use integer and rational arithmetic in Python
and SymPy. The program \texttt{b\_dictionary.py} verifies the integral
monodromy conjugations, and \texttt{b\_families.py} checks the full list
of requested multiplicities and the weighted-ring dimension formulas
by independent monomial counting. The program \texttt{b\_topology.py}
checks the explicit rational Mayer--Vietoris boundary matrices and
their nonzero determinant for arbitrary admissible twist data.
The C programs compute the
cohomology of every elementary double-complex summand directly from
its matrices and check the fibre-intersection sign in an oriented
real period frame. The D programs verify root-line cohomology,
equivariant truncated Koszul ranks and division-polynomial identities.
These finite checks accompany the proofs; agreement with an index
does not substitute for a sheaf calculation.

For the period scalar the working precision is one hundred decimal
digits. The saved output records the modular Fourier evaluation and
an independent real-period quadrature, the Newton iteration on the
Weierstrass equation, its residual and the approach parameter. The
forty-digit values printed in the paper are conservatively truncated.
The proof of nonvanishing uses the good-reduction elliptic curve and
its marked Abel coordinate, so it does not infer nonvanishing from
rounded decimal output. The order-three leading coefficient is
independently checked using modular Fourier and theta evaluations.

The numerical outputs do not contain rigorous interval enclosures.
In particular they certify agreement at the stated working precision,
not a machine-verified error bound. Every asserted nonvanishing used
in a proof has a separate exact argument. We retain the two distinct
notions of a global representative defined by an elliptic Green
operator and a finite atlas of coefficient functions; the latter
calculation for the representative $Q$ is explicitly unfinished in C3.8.
