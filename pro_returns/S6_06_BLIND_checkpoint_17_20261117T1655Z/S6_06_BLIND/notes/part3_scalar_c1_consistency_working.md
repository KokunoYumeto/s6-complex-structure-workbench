# A separate scalar-loop C1 consistency diagnostic

Working diagnostic, 17 November 2026. This note assigns no return
class and changes no proved scalar or source statement.

The completed source-zero argument DZ uses only the native diagonal
star \(C_2\), its explicit seam, the literal pullback product and
the actual \(C_2\) Cox flop. Its right integer is independent of
the scalar order \(N\). The following broader substitution is
not used in that proof.

For a fixed-source scalar phase loop, the displayed torus-period
coefficients suggest the raw winding matrix
\[
 B_{\rm raw}=\begin{pmatrix}0&0\\0&m\end{pmatrix},
\]
when the scalar is \(\lambda=r^m\). On a double parameter loop,
the formal normal data in the same three transition rows are
\[
 t=m,\qquad l=(2m,0,2m),\qquad
 w=(0,1,-1),\quad d=(-2,-1,-1).
\]
The expressions \(I_i=tw_i+d_i(l_i-t)\) and
\(W_i=tw_i-d_i(l_i-t)\) then give
\[
 I=(-2m,2m,-2m),\qquad W=(2m,0,0).
\]
The formal chain and ambient-frame substitutions give doubled
right integers \(-2m\) at \(C_1\), and \(0\) at \(C_2\).
The former would not agree with applying the already proved
K31 scalar formula to the two adjacent physical-vertical-edge
fans, where the displayed scalar return has \(S=1\) on each.

This is currently an identified comparison to check, not a
theorem or a refutation of either geometric proof. In particular,
the complete scalar family's parameter closing, the native
\(C_1\) boundary product, and its family Cox arrow must be put
in the same marked coordinates before these substitutions can
be interpreted as actual relative integers. The DZ proof
establishes its own source-zero \(C_2\) arrows; it does not
supply that omitted scalar \(C_1\) comparison.

For the DZ target \(C_2\), this raw scalar substitution gives zero
and hence retains the expected scalar independence of the
new first-diagonal-flop difference. No general-fan extension of
DZ is made on the basis of this diagnostic.
