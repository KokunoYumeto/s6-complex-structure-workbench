\(T_\Phi=(X\times\mathbb R)/((x,t+1)\sim(\Phi x,t))\).

parameter covering has the actual map
\[
 T_{\Phi^d}\longrightarrow T_\Phi,
 \qquad [x,t]\longmapsto[x,dt],
 \qquad e^{2\pi it}\longmapsto e^{2\pi idt}.
\]
The source relation maps to
\((x,dt+d)\sim(\Phi^d x,dt)\), so this is exactly the
pullback torus with the retained fibre and physical-circle maps.

in \(\Theta_7\) through \cref{night:P3F.5,night:P3K.5,night:P3K.68}.

\]
