(\cref{iv:correction:P3K.10}).}
\RungOne
\begin{enumerate}[label=\arabic*.]
\item Retain $R=t^2+1$, $f=R^2+t$,
  $g=R^3+\tfrac32tR+\tfrac38$ and
  $y^2=x^3-3fx+2g$, with $G=(R,\sqrt3/2)$.
  Its actual line is $\mathcal O(8G-O)$, its suspension is
  translation by $-G$, and its stated ordinary order-one cap
  gives the constructed sphere family.
\item The actual reference page has $(H,\chi)=(8,1)$.
  The dual-line and inverse-closing maps above give physical
  pair $(24,24)$ and index $(96-24)/24=3$.

  $\mu=3/28$ and oriented class three. The nonzero class
  satisfies the mapping-torus criterion of \cref{night:P3F.24}.
\item An actual positive $N$-fold parameter pullback concatenates
  this return $N$ times, giving class $3N$. Since
  $3\cdot19=1$ modulo 28, these pullbacks realize every class.
\end{enumerate}
