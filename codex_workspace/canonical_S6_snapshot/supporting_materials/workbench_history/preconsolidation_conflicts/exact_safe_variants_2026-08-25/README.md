# Exact safe predecessor variants

These three files are byte-exact, portable variants from the 25 August
human-organized project. Their paths collided with later versions during
consolidation, so descriptive filenames are used here. They are historical,
not current entry points.

Machine-specific predecessor records were not copied byte-for-byte into the
public project. Their mathematical or workflow content is preserved in the
sanitized history copies documented by `../../PROJECT_MERGE_MAP.md`.
