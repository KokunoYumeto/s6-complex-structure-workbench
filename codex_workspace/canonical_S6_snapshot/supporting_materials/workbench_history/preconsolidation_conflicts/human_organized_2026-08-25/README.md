# Supporting materials index

- `audit_annotation_sources/` — editable reader guide, page-badge layer, and annotation appendix sources.
- `peer_reviews/` — Reviewer A, Reviewer B, Codex/Reviewer C, and the superseded packet-only report, each with its retained evidence.
- `manuscript_sources/` — reconstruction sources, modular parts, provenance records, and archival standalone variants.
- `reproducibility/` — exact-algebra scripts and results, source checks, build scripts, and QA tools.
- `reference_pdfs/` — compiled annotated and clean reference PDFs.
- `metadata/` — the completed audit release manifest, file tree, and SHA-256 ledger.
- `project_documentation/` — build notes, audit README, QA receipt, rights/provenance note, and Reddit template.
- `archive/` — retained source and review packages.

The root `main.tex` is the public-facing entry point and imports the editable corrective addendum from `audit_annotation_sources/`; keep that file with the project. The current front matter is followed by the preserved reconstruction and indexed review appendix. The metadata in `metadata/` describes the current human-organized tree, while older release manifests retained inside review packages remain historical records of those packages.
