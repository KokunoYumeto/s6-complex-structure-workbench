# Frozen audit baseline

These two sources are independent, self-contained LaTeX documents retained as fixed references for the live notebook.

- `annotated_audit.tex` compiles to one reader-guide page, 108 annotated manuscript pages, and a 12-page audit appendix: 121 US-letter pages total.
- `clean_transcription.tex` compiles to the unannotated 108-page US-letter reconstruction.

Neither source requires another project file, shell escape, an external font, a bibliography tool, or a network fetch. Compile either with pdfLaTeX. Do not edit these files in this workbench; proposed mathematical changes belong under `../research/`.
