# Spectral, umbral, and original-family exact checks

These five independently executable checks supplement the complete proofs in
the current higher-rung draft, shared lattice/ES draft, and workbench.
Run each with Python 3. The spectral matrix checker additionally uses SymPy.
The remaining programs use the standard library. Logs and script SHA-256
values are supplied in this directory. Finite program output does not replace
the written global, analytic, p-adic or all-coefficient proofs.

Proof locators: ocb (full Albert orbit family), ncs (labelled spectral map),
d4i (global/local cubic image), nus (marked umbral/theta/Fricke maps),
pshift (retained analytic parameter identifications). In the cumulative
workbench the two higher-root label prefixes are h24:ocb and h24:ncs.
The existing bibliography credits Wilson, Yokota, Mare--Willems, and
Cheng--Duncan--Harvey. No third-party primary text is redistributed here.
