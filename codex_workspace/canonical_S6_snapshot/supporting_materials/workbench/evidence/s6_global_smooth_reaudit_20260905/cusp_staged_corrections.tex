% CHANGE 7. Insert after the normalization paragraph, original line 872,
% to make "opposite edges" an exact holomorphic identification.
For a neighboring vertex
\(v\in\{\pm e_1,\pm e_2,\pm(e_1-e_2)\}\), put
\[
 C_v=E_0\cap E_v,\qquad
 \bar\lambda_v=B_0v,\qquad
 \iota_v=\Psi_{B_0v}|_{C_v}:C_v\longrightarrow C_{-v}.
\]
Indeed, \(B_0\bar\lambda_v=B_0^2v=-v\), so this is exactly the
translation identifying the edge \(\{0,v\}\) with \(\{0,-v\}\).
For a primitive row \(a\in\mathbb Z^2\) with \(av=0\), the same
character \(w=\chi^{(a,0)}\) is a coordinate on each dense edge orbit.
The exact character pullback is
\[
 \iota_v^*w_{-v}
 =\exp\bigl(2\pi i\,aC(0)B_0v\bigr)w_v,
\]
because its power of \(t\) is \(-av=0\).  In particular, with
\(\mu_0=\mu(0)\), \(b_0=b(0)\), and the indicated same-character
conventions, the three maps are
\[
\begin{array}{c|c|c}
 v&a&\iota_v^*w_{-v}/w_v\\\hline
 e_1&(0,1)&e^{-2\pi i\mu_0}\\
 e_2&(1,0)&e^{12\pi i\mu_0}\\
 e_1-e_2&(1,1)&e^{-2\pi i(7\mu_0+b_0)}.
\end{array}
\]
For the last entry,
\[
 (1,1)C(0)B_0(e_1-e_2)
 =-6\mu_0-h(0)-(b_0-h(0))-\mu_0
 =-7\mu_0-b_0.
\]
Thus no entry of \(C(0)\) was discarded.  Each multiplier is nonzero;
the maps extend to the entire rational curves as the restrictions of the
ambient biholomorphisms.  The reverse map is \(\iota_{-v}\), with reciprocal
multiplier.  These are the precise opposite-side identifications used by
the normalization map.
