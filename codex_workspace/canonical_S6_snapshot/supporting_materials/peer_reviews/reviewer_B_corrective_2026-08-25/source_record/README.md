# Reviewer B source-record front door

This is a curated public subset of a larger 87 MB evidence container. Start
with `README_PUBLIC_SELECTION.md`, then use the corrective reports in
`../report/` and the retained historical evidence PDFs in
`../evidence/reference_pdfs/`.

`ARCHIVE_README_ORIGINAL.md` preserves the container's original front door.
Its relative links describe the complete external container and therefore do
not all resolve inside this curated subset. Exact inclusion/exclusion status
for every original file is in `REVIEWER_B_ARCHIVE_COVERAGE.json`.
